## 📖 Overview

The Smart Electric Distribution Box is a proposed monitoring system that uses multiple sensors and a microcontroller to collect information about electrical distribution conditions.

The presentation explores combining sensor data with a communication system to monitor parameters and help predict upcoming electrical loads on the grid.

It also discusses the potential implementation of smart metering in the agricultural irrigation sector.

## 🎯 Objectives

- Monitor electrical distribution parameters using sensors.
- Collect and process sensor data through a microcontroller.
- Explore wired or wireless communication for transmitting data.
- Investigate load prediction using collected sensor information.
- Explore smart metering applications in agricultural irrigation.

## ⚙️ System Components

According to the project presentation, the proposed system includes:

| Component | Purpose |
|---|---|
| Current sensor | Monitor electrical current |
| Earth leakage sensor | Detect earth leakage conditions |
| Temperature sensor | Monitor temperature |
| Humidity sensor | Measure surrounding humidity |
| Microcontroller | Collect and process sensor data |
| Communication system | Transfer information using wired or wireless methods |
| Voltage regulator circuit | Provide regulated voltage for electronic components |
| Transformer | Part of the proposed electrical distribution system |

## 🔄 Working Principle

1. **Data collection:** Sensors monitor electrical and environmental parameters.
2. **Data processing:** A microcontroller collects and processes the sensor readings.
3. **Communication:** The system explores transferring the collected data through wired or wireless communication.
4. **Load prediction:** The presentation proposes using sensor data to help predict upcoming grid loads.
5. **Potential application:** Smart metering can be explored for agricultural irrigation and distribution monitoring.

*The presentation describes the proposed concept; it does not establish that all these functions were implemented or experimentally validated.*

## 🌾 Application in Agricultural Irrigation

Smart electric metering and distribution monitoring could help support irrigation systems by providing information about electrical consumption and operating conditions.

Potential areas of application include:

- Monitoring irrigation-related electrical loads.
- Observing current and other electrical parameters.
- Identifying earth leakage conditions.
- Collecting data to support load analysis and future planning.
